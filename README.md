# VpsDealsWire VPS Price Dataset

Real scraped VPS deal prices from 32 providers, refreshed every 6 hours. Data is collected from each provider's official public pages. Maintained alongside https://www.vpsdealswire.com/

## Data

The dataset is stored in `vpsdealswire-dataset.json`. Each record contains the following fields:

- `title`
- `provider_name`
- `price`
- `currency`
- `offer_url`
- `source_url`
- `valid_until`
- `fetched_at`
- `provider_slug`
- `offer_id`
